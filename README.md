# Muhammad Huzaifa Hameed — Portfolio

A lightweight, responsive, static portfolio built with plain HTML and CSS. No paid hosting, database, or backend is required.

## Free hosting with GitHub Pages

1. Create a public GitHub repository named `huzaifa-portfolio` (or `<your-github-username>.github.io` for a root site).
2. Upload `index.html`, `style.css`, and `resume.pdf`.
3. In GitHub: **Settings → Pages → Deploy from a branch → main → / (root)**.
4. Save and wait for GitHub Pages to publish the site.

The site already links to the public LinkedIn profile and the included resume PDF.
